# Kurage 土砂災害ハザードマップ — 設置手順

住所から土砂災害警戒区域の内外を判定するシステムを、自社のサーバーに置く手順です。

## 用意するもの

| 項目 | 目安 |
| --- | --- |
| OS | Linux（Ubuntu 22.04 で動作確認） |
| CPU / メモリ | 2コア・4GB以上 |
| ディスク | 全国分で約8GB（1都道府県だけなら1GB未満） |
| ソフト | Docker、Docker Compose v2、Python 3.10以上 |
| 通信 | 国土交通省のサイトからデータを取得します（初回のみ） |

外部の有料APIは使いません。ランニングコストはサーバー代だけです。

## 1. データベースを立てる

```bash
cd khazard
docker compose up -d
```

PostGIS が `127.0.0.1:55433` で起動します。パスワードは
`KHAZARD_DB_PASS` 環境変数で変えられます（既定 `khazard_local`）。
**外部に公開する場合は必ず変えてください。**

## 2. Python の環境を作る

```bash
python3 -m venv .venv
.venv/bin/pip install fastapi "uvicorn[standard]" psycopg2-binary requests
```

## 3. データを取り込む

まず1つの都道府県で試すことをおすすめします（愛知県なら `23`）。

```bash
python3 scripts/load_a33.py 23
```

全国分を入れる場合は次のとおりです。回線にもよりますが30分〜1時間かかります。

```bash
python3 scripts/load_a33.py all
```

取り込みが終わると、使ったデータの出典と時点が `datasets` 表に記録されます。
**この記録が無いデータでは判定を行いません。**
いつ時点のデータかを示さずに「区域外」と答えるほうが危険だからです。

### 都道府県コード

| 01 北海道 | 13 東京 | 23 愛知 | 27 大阪 | 40 福岡 |
| --- | --- | --- | --- | --- |

その他は総務省の全国地方公共団体コードの上2桁です。

## 4. 起動する

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 18376
```

常駐させる場合は `systemd/khazard.service` を使います。

```bash
cp systemd/khazard.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now khazard.service
```

## 5. 動作を確認する

```bash
curl http://127.0.0.1:18376/healthz
```

取り込んだ区域数・都道府県数・データ時点が返れば成功です。

```bash
curl 'http://127.0.0.1:18376/api/check?q=愛知県西尾市吉良町乙川藤兼'
```

## 6. 社外に公開する場合

同梱の `php/khazard.php` は、レンタルサーバー（PHP）から自社サーバーへ
中継するためのものです。同じディレクトリに `khazard_config.php` を置きます。

```php
<?php
define("KHAZARD_BACKEND", "http://あなたのサーバー:18376");
```

公開するときは次に注意してください。

- アプリを `--host 0.0.0.0` で起動し、ルーターでポートを転送します
- 転送したポートは、中継元のサーバーからだけ届くように絞ってください
- 判定APIには1分20回の制限が入っています。必要に応じて `limited()` を調整します

## データを更新する

国土数値情報は年度ごとに更新されます。同じコマンドを実行すると、
最新版を自動で探して取り込み直します（`datasets` の時点も更新されます）。

```bash
python3 scripts/load_a33.py all
```

**年1回は実行してください。** 区域の指定は追加・変更されます。
古いデータのまま使い続けると、判定が実態と食い違います。

## 出典の表示について

このデータは公共データ利用規約（PDL1.0）で提供されており、
利用時には出典の記載が必要です。同梱の画面には次を表示しています。
**外して使わないでください。**

> 出典: 国土数値情報（土砂災害警戒区域データ）国土交通省 を加工して作成。
> この地図の作成にあたっては、国土地理院長の承認を得て、
> 同院発行の基盤地図情報を使用した（承認番号 平27情使、第585号）。

画面を作り替える場合も、出典と「加工したこと」の明記は残してください。

## 判定の限界（利用者へ必ず伝えてください）

- **公的な証明にはなりません。** 参考情報です
- **番地単位の判定はできません。** 住所から求めた座標は町丁目のおおよその位置です。
  実測では区域の縁から14〜50mずれた例がありました。
  250m以内に区域があるときは、その旨を画面に表示します
- **洪水の浸水想定は扱っていません。** 国土数値情報で配布されている
  都道府県別データが2012年版（2015年の水防法改正前の基準）のためです

これらの注意書きは画面に組み込んであります。消さないでください。
