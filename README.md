# Kurage 土砂災害ハザードマップ

（リポジトリ・ポート・systemd unit の略称は `khazard`。対外の名前は「Kurage 土砂災害ハザードマップ」）

住所を入れると、国土交通省が公開している土砂災害警戒区域のデータと照らして
区域の内外を判定します。公開URL: https://kurage.exbridge.jp/khazard.php/

## 設計の芯

この製品は「調べた気にさせない」ことを設計の中心に置いています。

1. **判定には必ずデータ時点を添える。** `datasets` 表に時点が無いデータは判定に使いません。
   黙って古いデータで「区域外」と答えるほうが危険なためです。
2. **古いデータ（既定5年超）を使った判定には注意書きを出す。**
3. **近くに区域がある場合は「区域外」と言い切らない。**
   住所から求めた座標は町丁目のおおよその位置です。実測では区域の縁から
   14〜50mずれた代表点が「区域外」と出ました（2026-09-05）。250m以内に区域が
   あるときは、地番での確認を促す注意書きを必ず添えます。
4. **一次情報への導線を必ず返す。** 本サービスの判定は参考であって公的な証明ではありません。
5. **出典と「加工したこと」を明記する**（公共データ利用規約 PDL1.0 の要件）。

## 構成

| 部品 | 中身 |
| --- | --- |
| ジオコーディング | 国土地理院 AddressSearch API（無料・キー不要） |
| 判定 | PostGIS（khazard-db :55433）ST_Contains |
| データ | 国土数値情報 土砂災害警戒区域(A33) 全47都道府県 179万区域 |
| 常駐 | systemd user unit `khazard.service` :18376 |
| 公開 | heteml の `khazard.php` から透過プロキシ |

## データ

| 項目 | 値 |
| --- | --- |
| 出典 | 国土数値情報（土砂災害警戒区域データ）A33 国土交通省 |
| データ時点 | 2026-03-06（提供元メタデータの作成日） |
| 区域数 | 1,793,171（全47都道府県） |
| 座標系 | JGD2011 地理座標系（EPSG:6668） |

洪水浸水想定区域は本製品では扱いません。都道府県別の旧版(A31 v2.2)は2012年版が最新で
2015年の水防法改正前の基準ですが、**1次メッシュ単位の第4.0版（2022年度）は現行基準（想定最大規模・
浸水継続時間・家屋倒壊等氾濫想定区域）を含む**ため、洪水・内水は別製品
「Kurage 洪水・内水ハザードマップ (kflood)」https://kurage.exbridge.jp/kflood.php/ で判定します。

## 使い方

```bash
docker compose up -d                      # PostGIS
python3 scripts/load_a33.py 23            # 愛知県だけ
python3 scripts/load_a33.py all           # 全都道府県
systemctl --user start khazard.service
curl 'http://127.0.0.1:18376/api/check?q=愛知県西尾市吉良町乙川藤兼'
```

## 地域ページ

`/khazard.php/area/<団体コード>` に 1,603市区町村＋47都道府県＋政令指定都市の区（147区）。
数字は `scripts/build_muni_stats.py` が A33 の住所文字列から数えて `muni_stats` / `ward_stats` /
`ward_unassigned` に保存した実測値。区の団体コードは総務省「全国地方公共団体コード」から
`scripts/fetch_wards.py` で `data/seirei_wards.json` を作る（照合の正典 krefuge の muni_vintage には区が無い）。
区は住所の区名だけで振り分け、区名が無い住所・旧区名（浜松市「北区」等）は振り分けずに市のページで件数を開示する。
区域0の区は、その市に振り分けられない区域が無いときだけページにする。

```bash
/usr/bin/python3 scripts/fetch_wards.py              # 区のコード表（総務省の改定時だけ）
systemd-run --user --scope -p MemoryMax=8G /usr/bin/python3 scripts/build_muni_stats.py
systemctl --user restart khazard.service
```

## 取り込みの注意

国土数値情報のGMLはGDALのGMLドライバではレイヤを認識できません
（2026-09-05 実測: ogrinfo はファイルを開けるがレイヤ0件）。
実体を直接持たず3段階の xlink 参照になっているためで、`scripts/load_a33.py` が
Curve → Surface → フィーチャ の順に解決します。
配布zipのパス区切りが `\` なので、Linuxでは展開時にファイル名へ `\` が入ります。
